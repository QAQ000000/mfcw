# 验证码发送限流

安装并启用插件后，短信验证码和邮件验证码发送入口分别共享以下限制：

- 同一手机号或邮箱地址发送冷却；
- 单手机号或邮箱地址每日发送上限；
- 短信、邮件各自的全站每分钟发送上限；
- 短信、邮件各自的全站每日发送上限。

插件使用手机号或邮箱地址的 SHA-256 摘要保存限流事件，不保存接收地址明文。后台插件配置可分别调整短信和邮件阈值。

限流事件在调用短信或邮件网关前记录，因此网关返回失败也会占用冷却时间和配额。这样在网关异常或攻击请求下仍能限制外部调用量；全站阈值应按实际业务量调整。

所有阈值均可设为 `0`，表示不限制该项。

插件保留原有 `sms_send_limit` 钩子作为旧安装兼容入口，覆盖升级时无需重新安装即可启用邮件验证码限流。
