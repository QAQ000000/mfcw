# 页面排版详细描述

本页提供新模板的文字排版方案，不把建议当作旧版实际渲染。描述中的“左栏、右栏、主区、底部”表示信息层级和
相对位置。旧前台认证与商品入口实测见[前台观察](38-front-browser-observations.md)。首批宽度、字号、间距和断点采用[组件规格](19-component-interaction-contract.md)，
具体线框采用[首批样板](24-first-batch-page-specs.md)；品牌颜色、图片和非首批视觉稿仍待确定。

## 公共排版骨架

### 官网

桌面端从上到下为：公告/顶部工具条（启用时）→ 主导航和 Logo → 首屏或页面标题 →
页面主内容 → 产品/帮助/联系方式入口 → 页脚。产品详情页通常采用“左侧产品说明、右侧
购买或咨询卡片”；文章页采用“左侧正文、右侧目录或相关文章”。移动端所有双栏改为
单列，购买/咨询卡片紧跟产品摘要，导航折叠为抽屉。

### 客户中心

桌面端从上到下为：顶部 Logo/语言/消息/账户 → 左侧客户导航 → 右侧页面标题和面包屑 →
主内容区。列表页主内容采用“顶部筛选和操作栏、下方列表、底部分页”；详情页采用“顶部
摘要卡、下方分组内容、右上或底部操作”；表单页采用“标题说明、分组字段、底部提交栏”。
移动端顶部保留 Logo、返回和账户入口，左侧导航收起为抽屉，双栏改为单列，操作按钮变为
全宽或固定底部操作栏，表格改为卡片或横向滚动。

### 购物车

桌面端采用“左侧商品/配置流程、右侧订单摘要”的双栏；结算时右侧摘要和支付操作保持
视觉连续。移动端改为“商品/配置 → 优惠和金额 → 支付操作”的单列顺序，提交按钮固定在
底部或摘要末尾，不遮挡错误提示。

### 后台

桌面端从上到下为：顶部管理员和系统状态 → 左侧可折叠菜单 → 面包屑/标题 → 筛选工具栏 →
表格或表单 → 分页/汇总。详情页可用标签页，但当前对象摘要必须位于标签页之前。移动端
侧栏变为抽屉，筛选折叠为筛选面板，表格改为字段卡片或横向滚动，批量操作集中到工具栏。

## 官网页面排版

| 页面 | 排版描述 |
| --- | --- |
| `index.html` | 首屏采用 Logo/导航上方的主视觉区，主标题和行动按钮位于视觉焦点；下方依次为产品入口、优势说明、新闻/帮助摘要和联系入口。移动端主视觉、按钮和产品卡片单列。 |
| `about.html`、`relation.html`、`management.html` | 顶部标题区后使用左右交替的图文段落；右侧或段尾放相关产品入口，移动端统一图在上、文在下。 |
| `contact.html`、`map.html` | 联系信息或站点链接使用分组卡片；地图/联系方式置于主区，表单或客服入口置于侧栏，移动端侧栏下移。 |
| `privacy.html`、`tos.html`、`aup.html`、`safeguard.html` | 标题和更新时间在顶部，正文使用窄内容列，目录或章节导航在桌面端位于左侧/右侧，移动端目录折叠。 |
| `cloud.html`、`hosting.html`、`server.html`、`dediserver.html`、`colocation.html` | 首屏为产品摘要和购买/咨询卡，下面按特性、规格、适用场景、FAQ 排列；购买卡桌面端靠右，移动端紧跟摘要。 |
| `cdn.html`、`domain.html`、`ssl.html`、`nat.html`、`antiddos.html`、`transfer.html` | 首屏突出服务能力和入口，规格/流程采用分组卡片，底部放咨询或购买行动；移动端卡片单列。 |
| `news.html`、`newscate.html`、`newscategory.html` | 顶部为分类和搜索，主区为文章列表，桌面端右侧放热门/公告摘要，移动端摘要移到列表后。 |
| `newsarticle.html`、`newscontent.html` | 标题、时间和标签在正文上方，正文为主列，右侧为目录/相关文章，底部为上一篇/下一篇。 |
| `newssearch.html` | 搜索框位于标题下方，结果按时间列表展示，空结果显示关键词和返回内容入口。 |
| `help.html`、`helpcate.html`、`helpcategory.html` | 搜索框和分类卡在顶部，文章列表位于下方；桌面端分类可保留左栏，移动端先显示搜索再显示分类。 |
| `helparticle.html`、`helpcontent.html` | 左侧正文、右侧目录/相关文章，底部提供相关问题和反馈；移动端目录折叠到正文前。 |
| `helpsearch.html` | 顶部保持搜索条件，主区显示结果、分类和匹配摘要，无结果时显示建议搜索。 |
| `404.html` | 居中显示错误说明、返回首页和客户中心两个主要按钮，不显示技术错误详情。 |

| --- | --- |
| `login.tpl`、`register.tpl`、`pwreset.tpl`、`bind.tpl` | 桌面端居中显示单列认证卡，品牌和语言在卡片上方，辅助入口在卡片底部；错误、验证码和二次验证紧跟对应字段，移动端卡片占满可用宽度。 |

| `clientarea.tpl` | 顶部欢迎和账户摘要；第二行是服务、账单、余额等统计卡；中部左右分别放到期/待支付提醒和快捷操作；底部放近期活动。移动端卡片按重要性单列。 |
| `details.tpl` | 页面标题后为资料表单；桌面端基本资料和联系方式分两列，底部统一保存；移动端字段单列，保存按钮固定在表单末尾。 |
| `security.tpl` | 顶部显示安全等级/状态，下面按密码、手机、邮箱、二次验证和登录提醒分卡片；每张卡独立操作并显示结果。 |
| `message.tpl`、`loginlog.tpl`、`systemlog.tpl`、`apilog.tpl` | 顶部筛选和未读/清理操作，下面为列表；每行显示时间、类型、摘要，详情用抽屉或展开区，移动端改为时间线卡片。 |
| `verified.tpl` | 顶部认证总状态和说明；下方并列个人认证、企业认证入口卡；已提交时显示审核进度和补充资料操作。 |
| `verifiedpersonal.tpl`、`verifiedenterprises.tpl` | 按“身份信息 → 证件/证明 → 联系方式 → 确认提交”分组；上传控件紧跟说明，底部显示隐私和提交按钮。 |
| `service.tpl` | 顶部筛选和购买/续费入口；主区为服务卡或表格，状态和到期日突出，右侧放进入详情/续费；移动端每个服务为一张信息卡。 |
| `servicedetail.tpl` | 顶部为产品名称、状态、到期日和主要操作；下方左侧为服务信息/图表，右侧为账单和快捷操作；移动端按“摘要 → 操作 → 详情 → 日志”排序。 |
| `service_product.tpl`、`service_hosting.tpl`、`service_server.tpl` | 顶部统一服务摘要；中部使用资源信息卡和凭据/网络信息分组；底部放续费、升级、工单入口，危险控制操作与普通操作分区。 |
| `service_cloud.tpl`、`service_cloud_server.tpl` | 顶部状态和电源操作；中部资源用量图表与实例信息左右布局；下部为重装、救援、VNC/KVM 等异步任务区。 |
| `service_cdn.tpl`、`service_domain.tpl`、`service_sms.tpl`、`service_soft.tpl`、`service_ssl.tpl` | 顶部对象摘要；中部按产品类型显示流量、域名、用量、授权或证书信息；右侧/底部放续费、配置、下载和验证操作。 |
| `billing.tpl`、`transaction.tpl` | 标题下为筛选/对应操作，主区列表显示状态、金额、时间和详情入口；移动端每条记录变为上下排列的信息卡。 |
| `invoicelist.tpl` 默认列表 | 顶部申请入口；申请时间、抬头、开票总额、申请状态、邮寄地址、快递、查看/待支付操作构成表格；底部分页。手机逐条按状态摘要、抬头金额、邮寄信息、操作排列。 |

| `invoicelist.tpl?action=invoiceapply&type=issue` | 个人/公司切换在首行，抬头和快递左右排列，地址整行；下部项目/金额/税率/税额表，底部税费、邮费、返回与确认；手机表单单列。 |
| `invoicelist.tpl?action=check` | 顶部性质、抬头、快递、邮寄地址；下部开票项目与税额表及税费/邮费摘要；新模板增加返回、状态/备注，手机信息单列。详细字段和状态见[财务页面](05-finance-pages.md#发票申请列表与详情)。 |

## 后台排版

以下覆盖 76 个 PHP View* 入口的布局分组，另须核对编译前端路由和动态菜单，见[路由盘点](22-admin-route-inventory.md)。布局描述是新模板方案，不证明现有接口已经提供所有建议操作。

| 页面组 | 排版描述 |
| --- | --- |
| 仪表盘/统计 | 顶部指标卡按业务优先级排列；中部为趋势图和对比图；底部为待处理列表和快捷操作。无数据时保留卡片标题并显示空态。 |
| 客户列表/详情 | 列表顶部搜索和状态筛选，表格中突出客户、状态、余额和操作；详情顶部固定客户摘要，下面使用标签页切换资料、服务、账单、交易、工单、日志和附件。 |
| 订单/产品 | 订单列表用筛选工具栏加表格，详情顶部显示订单状态和金额，中部显示商品/账单/服务链路；产品编辑按基本信息、价格、库存、配置项、模块、上游关联分组。 |
| 财务 | 列表优先显示状态、金额、客户、时间和流水号；详情将金额摘要置于顶部，项目明细居中，支付/退款/调整操作置于右侧或底部并二次确认。 |
| 工单 | 列表使用筛选加未读标记；详情顶部显示工单状态和部门，中部是消息时间线，底部是回复和附件，侧栏显示客户/服务上下文。 |
| 资源/上游 | 顶部显示连接状态和最近同步；中部为资源/接口表格，详情或编辑采用分组表单；危险的重置、删除和控制操作与普通保存分开。 |
| 系统/权限/插件 | 左侧为设置分组，主区为表单或权限树；保存结果、当前生效范围和需要清缓存/重启的提示必须紧跟操作。 |

## 视觉稿交付格式

每个页面在真正开始模板开发前，需补充一张桌面线框、一张移动端线框，并在图旁标记：
公共布局、字段来源、权限、接口、状态、按钮行为、空态和错误态。这样“排版描述”才会
从结构基线升级为可直接验收的视觉设计。
