# 组件与交互契约

组件先定义行为，再定义视觉。所有组件必须支持权限、加载、错误、空态、禁用、提交中和移动端状态，业务页面不得复制一套相似但语义不同的实现。

## 基础组件

| 组件 | 必须定义的状态 | 关键要求 |
| --- | --- | --- |
| 按钮 | 默认、悬停、禁用、提交中、成功、失败 | 高风险操作显示确认和影响范围，不只靠颜色区分 |
| 表单字段 | 空、聚焦、校验错、只读、脱敏、上传中、结果待核对 | 错误紧跟字段，失败保留安全草稿；可能部分保存时另读服务器基线，不自动重试 |
| 筛选器 | 默认、已筛选、展开、加载、清空 | 筛选值可恢复，移动端收进面板 |
| 表格 | 加载、空、错误、选中、批量处理中 | 固定关键列；移动端卡片或横向滚动 |
| 分页 | 首页、末页、无数据、加载中 | 保留筛选和排序，不允许无界查询 |
| 抽屉/弹窗 | 打开、关闭、加载、确认、失败 | 关闭前提示未保存内容；焦点锁定和键盘可用 |
| 通知 | 成功、失败、警告、处理中 | 文案说明下一步，不暴露堆栈和凭据 |
| 状态徽标 | 正常、处理中、失败、终态、未知 | 显示文字和可访问名称 |
| 时间线 | 初始加载、分页、附件失败、消息发送中 | 失败消息可重试，不能重复发送 |

## 金额、敏感信息和上传

金额统一由服务端格式化，前端只展示计算结果；折扣、税费、余额和可退款金额必须标记来源。身份证、Token、密码、支付参数默认遮罩，查看/复制/下载按权限和审计处理。上传显示大小、类型、进度、失败和重试，下载链接采用后端授权的短时地址。

客户资料接口可能先写主资料再返回自定义字段错误，因此失败状态需要显示待核对结果，保留草稿与服务器新基线供比较。具体行为见[后台样板契约](26-admin-pilot-contract.md)。

## 响应式断点

以下数值是首批新模板的实施基线，不是对旧模板 CSS 的描述。若品牌设计调整，统一更新此表及首批线框，不允许逐页自行增加断点。

| 参数 | 首批值 | 重排/状态 |
| --- | --- | --- |
| 手机 | <768px | 单列，导航抽屉，操作命中区域至少 44×44px |
| 平板 | 768–1199px | 侧栏收为 64px；表格内部滚动，详情次要信息下移 |
| 桌面 | ≥1200px | 导航 224px；主区 min-width:0，摘要栏 320px |
| 内容 | 客户区 max-width:1280px；后台随视口，内部 min-width:0 | 桌面页边距 24px，手机 16px；栏距 24px |
| 字号/行高 | 正文 14/22px，字段 14/20px，页标题 22/30px，分区标题 16/24px | 不随视口缩放字体；长文案换行，letter-spacing:0 |
| 间距 | 4/8/12/16/24/32px | 字段标签到控件 8px，字段组间 16px，分区间 24px |
| 控件 | 桌面输入/按钮 36px，紧凑工具 32px；手机主要输入/按钮 44px | 高度稳定，提交时 spinner 不改变宽度；工具图标带可访问名称/tooltip |
| 表格 | 表头 40px，单行最小 44px，单元格横向 12px；可换行行高自然增长 | 密度按钮切舒适 52px；固定列在窄屏按可用宽度降级 |
| 弹窗/抽屉 | 表单弹窗最大 640px，确认 440px；抽屉宽 480px | 手机宽 calc(100% - 32px)，最大高 calc(100dvh - 32px)，正文内滚动 |
| 圆角/边界 | 普通控件 4px，弹窗/重复项目 8px | 页面分区不套浮动卡片；数据区域用分隔线和留白 |
| 顶栏/固定区域 | 顶栏 56px；固定底栏按内容自然增高 | 正文预留实际高度；键盘弹起不遮字段/错误，安全区额外留白 |

横向表格只在自身滚动容器溢出，整页不得横向滚动。标签可换行；tabs 超长时独立滚动并保持选中项可见。加载态、空态、失败态使用相同容器最小高度，避免列表整体跳动。

## 富文本和错误

富文本仅在明确的可信管理员边界渲染；客户内容、上游响应、邮件正文和工单内容默认转义或隔离。错误组件显示业务可理解的原因、重试或联系入口，开发细节进入受控日志。
