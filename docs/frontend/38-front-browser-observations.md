# 副本前台匿名页面实测

2026-10-03，在用户提供的副本站点 `http://127.0.0.1/` 使用独立 WSL/Linux Chrome / Playwright 上下文观察。未使用管理员凭据登录客户中心，未注册、发送验证码、加入购物车、下单、支付或执行服务操作。只导航公开页面并切换登录标签；API和页面初始化仍可能有应用既有副作用。

## 实际主题与入口

| 范围 | 实际加载资源 | 页面 |
| --- | --- | --- |
| 官网 | `/themes/web/zjmf/assets/` | `/` 首页 |
| 客户中心认证 | `/themes/clientarea/default/assets/`、`assets_custom/` | `/login`、`/register`、`/pwreset` |
| 购物车 | 客户中心default公共外壳 + `/themes/cart/default/` | `/cart` 商品浏览/空数据页 |

资源路径只确认本次渲染结果；未导出私有主题配置，也未做数据库切换或缓存验收。不能把官网主题和客户中心/购物车主题看作一个统一开关。

## 页面排版与交互

| 页面 | 桌面实际排版 | 手机及可观察交互 |
| --- | --- | --- |
| 首页 | 约74px顶栏、主视觉轮播、产品入口、服务指标/图文区、页脚；导航含产品/支持/关于下拉及登录注册 | 390/320px下顶栏约69px，出现折叠菜单按钮；整页无横向溢出。未点击手机菜单或轮播按钮 |
| 登录 | 左侧背景图约840px，右侧认证区约600px（1440px视口）；右侧为手机/邮箱标签、账号/密码、验证码登录/找回密码、登录及注册入口 | 390/320px无整页横向溢出；默认手机登录，点击邮箱标签后可见字段变为邮箱/密码。未提交登录或发送验证码 |
| 注册 | 与登录共用认证外壳；手机/邮箱标签，手机号或邮箱、验证码、密码与确认密码、协议勾选及注册 | 390/320px无整页横向溢出；默认手机分支。未提交或测协议/校验错误 |
| 找回密码 | 共用认证外壳，手机/邮箱分支、验证码发送、密码与确认密码、重置 | 只观察1440px可达性与字段；未发送验证码/提交，手机布局NOT RUN |
| `/cart` | 70px左右顶栏、约250px左导航；正文为标题/面包屑、商品分类/搜索左列与右侧商品区；本次商品区显示“暂无数据” | 390/320px无整页横向溢出；未选择具体商品或进入配置。这是当前入口分支，不是购物车结算明细页 |

认证页的旧桌面布局不是居中单列认证卡；文档中居中、自适应表单是新设计方案。`/cart` 的商品浏览和空购物车/结算分支也须分别设计，不能仅按URL认定为已有商品的购物车。

## 状态与问题

| 检查 | 结果 | 边界 |
| --- | --- | --- |
| 官网/认证/购物车入口 | PASS（读取） | 所观察最终文档HTTP=200；不代表业务接口和提交通过 |
| 匿名进入客户中心 | PASS（跳转） | `/clientarea`、`/billing`、`/supporttickets`最终导航至`/login`；不证明已登录对象权限 |
| 首页/登录/注册/cart宽度 | PASS（局部布局） | 1440/390/320px下document.scrollWidth等于视口；仍须测试控件可操作、弹窗、软键盘及长文本 |
| 客户中心已登录页面 | NOT RUN | 未提供受控客户fixture或客户会话；后台账号不是客户账号 |
| 下单/支付/服务/工单提交 | NOT RUN | 未发生业务写入，无模块/支付沙箱验收 |
| 图片资源 | FAIL | 首页/认证的`/upload/logo.png`返回404；cart另有logo-colours及CN/US/HK国家图路径缺图。先确认副本上传资源是否完整，不能直接归因模板代码 |
| 官网字体资源 | FAIL（加载） | 控制台报告fa-solid-900.woff2解码失败，图标字体质量待核对 |
| 旧官网脚本提示 | 待追溯 | scripts.min.js报告WHMCS Base URL变量缺失；未据此确认某业务故障或修复 |

上述缺图/字体问题只记录现状，没有修改上传文件、主题或站点配置。页面出现开发调试浮层，截图对其遮盖；本环境观察结果不用于生产发布验收。
