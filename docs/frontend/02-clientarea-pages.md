# 客户中心页面

## 公共外壳

客户中心由 `ViewClientsController` 和 `ViewBaseController` 处理，默认主题位于
`public/themes/clientarea/default/`。登录前页面包括登录、注册、找回密码和绑定；其他
客户页面需要有效客户会话。客户被停用或关闭时应显示退出/联系管理员状态，不能继续展示
私有数据。

## 页面契约

| 页面 | 布局 | 主要数据/操作 | 必须验证 |
| --- | --- | --- | --- |
| `/login` | 登录方式切换、验证码/二次验证、OAuth 入口 | 邮箱、手机、密码、验证码 | 错误次数、验证码、登录成功跳转 |
| `/clientarea` | 账户摘要、服务统计、到期/账单提醒、快捷入口 | 客户信息、服务和未付账单 | 空账户、停用账户、移动端卡片 |
| `/service` | 服务列表、状态筛选、到期信息、操作入口 | `host`、产品、状态 | 只能访问当前客户服务，状态标签与后端一致 |
| `/servicedetail` | 服务信息、控制按钮、账单/流量/配置区域 | 主机详情和模块接口 | `hostid` 归属、处理中、失败、二次确认 |
| `/details` / `/security` | 资料、安全设置、密码和联系方式表单 | 客户资料、绑定方式、二次验证 | Token、敏感字段遮罩、保存失败回填 |
| `/verified` | 个人/企业认证状态和资料表单 | 认证状态、证件/企业字段 | 未提交、审核中、通过、驳回和重新提交 |
| `/supporttickets` / `/viewticket` | 工单列表、详情时间线、回复区 | 工单、回复、附件 | 工单归属、关闭后回复、附件下载权限 |

## 交互规则

- 所有客户资源操作以服务端 `uid` 和主机归属为准，不能信任查询参数中的客户 ID。
- 服务控制、重装、救援、取消和支付等操作必须显示当前状态，并在请求期间禁用重复点击。
- 接口返回业务失败时保留用户输入，显示可理解的错误；超时后允许重新查询最终状态。
- 页面刷新和浏览器后退后，订单、支付和主机状态必须从服务端重新加载。

## 验收

使用普通客户、无服务客户、存在未付账单客户和已停用客户各验证一次；桌面和手机各验证
登录、首页、服务详情、账单和工单主流程。管理员数据不能通过客户页面或模板变量泄漏。
