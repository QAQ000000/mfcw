# 服务与主机页面

服务页面围绕 `host`、产品和服务器模块展开。模板包括 `service.tpl`、按产品类型划分的
`service_*.tpl` 以及 `servicedetail.tpl`，动作由 `home/Host`、`home/provision`、`home/dcim`
和服务器模块处理。

## 布局区域

1. 服务标题、产品名称、主机标识和状态标签。
2. 到期日、账期、续费/升级入口和待处理账单提示。
3. 服务信息、凭据展示、流量图表或模块自定义内容。
4. 电源、重装、救援、KVM、VNC 等操作区。
5. 操作结果、异步任务进度和工单支持入口。

## 状态规则

| 状态 | 页面行为 |
| --- | --- |
| `Pending` | 显示等待开通/同步，隐藏不适用的控制按钮 |
| `Active` | 显示可用服务和授权的控制操作 |
| `Suspended` | 显示暂停原因和续费/恢复路径，限制普通控制操作 |
| `Cancelled`、`Fraud`、`Deleted` | 只展示历史信息和允许的账单/工单入口 |

状态值以 `app/config/public.php` 和 `app/common/logic/Host.php` 为准。模板不能自行把
上游返回的任意字符串当作可操作状态。

## 操作验收

每个按钮都要验证显示条件、客户归属、二次确认、请求中禁用、成功、失败、超时和刷新后
最终状态。临时密码、救援信息、VNC/KVM 链接等敏感数据不得写入 URL、日志或无权限模板。
