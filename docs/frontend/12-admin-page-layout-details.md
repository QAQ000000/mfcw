# 后台逐页排版与交互契约

本文是后台新模板的文字布局方案，覆盖 `data/route/admin.php` 中 76 个 PHP View* 入口，不代表后台完整页面清单或已经完成开发契约。编译前端的 229 条路由记录及对应关系见[静态盘点](22-admin-route-inventory.md)和[页面对应关系](23-admin-page-crosswalk.md)。页面入口以 `config("database.admin_application")` 的实际前缀拼接。

**阅读规则**：文中的位置、尺寸、抽屉、确认、筛选和附加操作是重构建议；表格列只有在对应 View* 方法中定义时才是静态现状。接口、权限和状态规则必须按[真实接口契约](13-page-api-contract.md)核对。未提供接口依据的操作不得进入开发范围。

View* 返回 `data = "test"` 只说明该视图是占位实现，不能据此判断业务缺失。报表等功能已有独立控制器；当前缺口是新旧页面映射和运行验证。

用户已确定后台采用新建工程方案。本文作为逐页设计输入，后续每页须补齐旧页面现状证据、桌面/手机布局、真实字段与操作、各交互状态、接口/权限及验收步骤；额外编译页面也纳入映射。工程方向与流程见[构建文档](16-frontend-architecture-build.md)。

旧产物实际结构见[229 条路由逐页证据](27-admin-built-page-evidence.md)，核心排版/跳转/表单的可读说明见[旧后台解读](28-admin-built-layout-reading.md)。本文的建议尺寸和控件不冒充旧版事实；新设计差异逐页另列。旧客户列表的列、45px 表格高度、800/768px 工具区断点，以及资料页三个分组等已有实际产物依据。

## 1. 统一后台外壳

### 桌面端

1. **顶栏（56–64px）**：左侧 Logo、折叠菜单按钮和当前站点名称；中部可放全局搜索；右侧依次显示队列/系统状态、通知、语言、管理员姓名、退出和“查看前台”。系统状态只显示可验证的状态和最近检查时间，不能在前端自行推断“正常”。
2. **左侧菜单（220–248px）**：按客户、业务、财务、工单、商品、资源、统计、系统分组。菜单项根据管理员权限返回结果渲染；没有权限的入口不通过前端隐藏来代替后端拒绝。当前菜单、未读数量和需要处理的数量使用独立视觉标记。
3. **内容头部**：面包屑 → 页面标题 → 一句用途说明；右侧放页面级主操作，例如“新建”“导出”“同步”。详情页必须保留返回列表入口和当前对象标识。
4. **工具栏**：第一行放关键词、状态、时间、客户/产品等主要筛选；第二行放批量操作、视图切换、列设置和刷新。筛选提交后保留在 URL 或可恢复的页面状态中。
5. **主区**：列表采用表格，详情采用摘要卡 + 标签页，编辑采用分组表单。主区宽度不足时表格横向滚动，禁止把金额、状态和操作列挤成不可读的图标。
6. **底部**：分页、总数、当前筛选摘要、异步任务进度或保存结果。批量操作结果必须说明成功、失败和跳过数量，并提供失败原因入口。

### 移动端

顶栏保留 Logo、返回、通知和管理员菜单；左栏变为抽屉。筛选收进“筛选”面板，表格默认转换为“主字段 + 状态 + 操作”的卡片，确需比较的宽表才允许横向滚动。详情标签页变为横向滚动或下拉选择；危险操作不能藏在长按手势中。固定底部操作栏要避开键盘和安全区域，并在提交失败时自动滚到第一处错误。

### 统一控件和状态

- 列表过滤至少支持关键词、状态、时间范围和分页；加载时保留表头和筛选值，使用骨架或行级加载，不整页闪烁。
- 空态说明当前筛选条件，并提供“清空筛选”或“创建第一条”入口；无权限显示权限名称和联系管理员提示；接口错误显示重试，不展示堆栈。
- 删除、退款、提现审核、余额调整、重装、关机、重置密钥、批量发送等动作必须二次确认；确认框显示对象、影响范围、不可逆性和审计操作者。
- 所有状态徽标同时提供文字；`Pending`、`Active`、`Suspended`、`Deleted`、支付中、已支付、失败等状态不能只用颜色区分。
- 详情页操作按钮根据后端权限和对象状态返回；按钮禁用时显示原因。成功后刷新受影响的卡片、表格和时间线，并保留操作结果。
- 敏感字段（身份证号、支付凭据、API 密钥、密码、上游 Token）默认脱敏，查看、复制和下载分别记录审计日志。

## 2. 仪表盘、插件和全局入口

### `/index`（`ViewAdmin/index`）

顶部放“今日/本月”时间切换和最近刷新时间；第一行指标卡显示客户数、待支付账单、待处理工单、待审核认证等已由接口提供的指标。中部左侧为收入/订单趋势，右侧为状态分布；底部按权限显示待处理列表和快捷入口。无统计接口或数据为空时保留卡片标题并显示“暂无数据”，不得填充演示数字。错误时只影响对应卡片并提供单卡重试。

### `/plugins`（`ViewPlugins/index`）

顶部为关键词、启用状态和插件类型筛选，右侧放“上传/安装”或“刷新插件”入口（只有后端提供时才显示）。主区卡片或表格显示插件名称、标识、作者、版本、描述、状态和操作；操作区包含启用、停用、配置、更新、卸载，危险操作显示依赖和影响范围。插件列表由 `plIndex` 返回，空态区分“没有插件”和“搜索无结果”。

## 3. 客户管理页面

客户相关页面都在内容头部显示“客户：姓名（ID）”上下文。客户详情标签顺序固定为摘要、资料、服务、账单、交易、余额、工单、日志、通知、附件、推广、CRM、邮件；直接打开子页面时仍显示客户摘要和返回客户入口。

### `/clients`

顶部左侧为姓名/手机号/邮箱/ID 搜索，第二行提供状态、客户组、等级、销售和创建时间筛选；右侧放新建客户、导出和批量分组。表格列按当前契约为：ID、姓名、手机号/邮箱、服务、收入/支出、余额、创建时间、客户等级、客户分组、状态、销售、操作。操作包括查看、编辑、登录客户中心、停用/启用、调整分组和删除（删除需明确关联数据）。移动端卡片优先显示姓名、状态、余额和服务数。

### `/clientsauthentication`

筛选区提供认证类型、审核状态、提交时间和姓名/证件号（证件号仅支持脱敏匹配）。表格列为 ID、姓名、认证名称、身份证号码（脱敏）、认证方式、认证类型、状态/原因、提交时间、操作。详情抽屉分身份资料、证件附件、审核记录；通过、驳回、要求补充资料均需填写原因并写入审计。附件加载失败要能单独重试。

### `/clientsresources`

该页采用客户资源汇总列表：ID、客户姓名、收入、余额、创建时间、添加销售。顶部支持客户、销售和时间筛选；“添加销售”打开带当前客户摘要的选择抽屉，保存后刷新该行并记录变更前后销售。空态时提供回到客户列表入口。

### `/resourcepool`

该 View* 方法注释为“资源方入驻审核”，但实现仍调用 `UserManage::clientList()` 并复用客户表格，不能把它写成手工资源分配页。新模板上方放资源方审核状态，主区放申请人/状态/详情；实际审核数据和操作需从资源方控制器及 `/resource-pool` 前端路由继续核对。手工资源管理属于 `/munualresource`。

### `/salesstatistics`

顶部为销售、客户、产品、时间和收入类型筛选；第一行显示销售额、提成和订单数卡片；主区表格列为客户、产品、金额、提成、类型，底部提供导出和汇总。图表只使用接口返回的时间序列；无数据时不要显示零值折线。

### `/affiliates`

筛选区提供推广人、时间和状态；表格列为 ID、姓名（公司名）、访问数量、注册数量、订购数量、总佣金、已提现佣金、操作。详情侧栏显示推广链接、规则和提现记录；调整佣金或冻结推广资格需二次确认并记录原因。

### `/massmailsms`

采用三步向导：选择客户/分组 → 选择邮件或短信模板并预览 → 确认发送。选择区显示预计人数和无效联系方式；编辑区限制变量并提供渲染预览；确认页显示发送渠道、费用提示、计划时间和取消入口。发送中显示进度、成功/失败/跳过数，失败可下载明细；禁止在浏览器重复提交。

### `/configclientgroups`

列表模式下表格列为客户组名称、组颜色、操作；若当前实现返回另一种数据，则按分组名、操作的窄表格渲染，并在文档和接口契约中标明差异。新增/编辑使用名称、颜色、说明、默认组和状态分组；删除前显示组内客户数量及迁移目标。

### `/configauthentication`

采用左侧认证类型导航、右侧配置表单。表单按个人认证、企业认证、审核规则、必填资料和通知模板分组；每组底部显示保存范围和立即生效说明。关闭认证方式需说明已有申请如何处理，并要求管理员权限和审计。

### `/configclientscustomfields`

顶部为字段类型和启用状态筛选，主区显示字段名、类型、是否必填、适用客户组、排序和操作。编辑抽屉分基本信息、选项值、显示条件和数据校验；修改字段类型或删除前显示已有数据影响。控制器当前返回 `customfields`，新模板需保留未知字段的兼容展示。

### `/configaffiliates`

表单按启用开关、归因窗口、佣金比例/固定额、适用产品、提现门槛、结算周期和通知分组。右侧固定显示规则预览和示例订单计算；保存后提示生效时间，历史佣金不得被前端静默重算。

### `/configclientslevel`

表格列为客户等级、收入、购买商品数量、累计登录次数、最近登录次数、续费次数、最近续费次数、操作。新增/编辑使用等级名称、条件优先级、颜色和升级/降级规则；冲突条件以校验列表显示，批量重算必须显示任务进度。

### `/clientssummary`

客户详情首页采用摘要卡：姓名/公司、客户 ID、状态、等级、余额、收入/支出、服务数和最近登录。下方为待处理提醒和最近活动；右上放编辑、登录客户中心、停用/启用。任何金额调整入口必须跳转到带原因的专用表单。

### `/clientsprofile`

两列资料布局：左列基础身份和联系方式，右列客户组、等级、销售、状态和自定义字段；移动端单列。保存区固定在底部，失败时按字段回填错误。身份证、手机号、邮箱修改按当前系统要求触发验证或二次确认。

### `/clientsservices`

表格列为 ID、产品/服务、IP、金额、产品类型、付款周期、订购时间、到期时间、状态、操作。工具栏支持客户、状态、到期区间和产品筛选；操作包括查看、续费、暂停/恢复、取消和进入控制台。异步开通/暂停显示任务状态和轮询失败重试。

### `/clientsinvoices`

表格列为账单 ID、账单生成日、预期日、支付日、总计、支付方式、状态、账单类型、操作。顶部显示客户摘要和待付金额；批量支付、标记已付、作废和退款按权限显示，并要求原因、支付渠道和审计记录。

### `/clientstransactions`

表格列为 ID、交易记录号、生成日、付款方式、描述、收入、手续费、支出、操作。金额列使用收入/支出分列，详情抽屉显示关联账单、订单、网关回调和操作者；人工调整只能从专用表单进入。

### `/clientscredit`

这是“信用管理”。顶部放 `credit_limit`、`credit_limit_used`、`credit_limit_balance`、使用比例和认证/启用状态；中部放账单生成日、还款期限、还款日期及本月账单；下方放信用额支付明细、还款账单和额度调整日志。启用/修改/关闭分别使用 `POST/PUT/DELETE {A}/credit_limit`，成功后刷新摘要、日志、账单。View* 当前读取的是客户 profile，新模板还需显式读取信用额 API。此处不提供余额冻结/解冻功能。

### `/clientssupporttickets`

表格列为 ID、主题、状态、部门、提交时间、上次回复；工具栏支持状态、部门、时间和关键词。行内显示未读标记，点击进入 `/clientssupportticketdetail`；批量关闭或转部门前显示未读和待回复数量。

### `/clientssupportticketdetail`

左侧主区是按时间倒序的消息时间线，消息显示发送人、时间、正文和附件；右侧显示客户、关联服务、部门、处理人、状态和 SLA。底部回复编辑器支持附件、内部备注和转发；关闭、重开、转部门和删除附件需要权限及确认。

### `/clientslog`

筛选区提供时间、动作、管理员、IP 和关键词；表格列为 ID、时间、描述、用户名、IP 地址。详情抽屉显示请求上下文、对象 ID 和结果，敏感参数脱敏；导出需要单独权限。

### `/clientsnoticelog`

顶部用短信、邮件、站内信三个标签。短信列为 ID、时间、短信内容、用户名、电话、是否成功、失败原因、IP；邮件列为 ID、时间、主题、收件人、是否成功、失败原因、IP；站内信列为发送时间、标题、用户、状态。内容默认折叠，失败原因可展开并提供重试入口（后端支持时）。

### `/clientsattach`

表格列为附件名称、上传时间、上传人、文件名、备注、操作。顶部按类型、时间和上传人筛选；预览、下载、替换和删除按权限显示。下载链接短时有效，删除需确认关联对象。

### `/clientsaffiliate`

客户推广页显示推广人关系、访问/注册/订购统计、佣金和提现流水；右侧放解绑、冻结和查看规则。解绑或更换归因要求原因并说明历史佣金处理方式。

### `/clientscrm`

采用“客户摘要 + CRM 字段卡 + 联系记录时间线”。字段卡支持标签、销售、来源、下次跟进时间和备注；时间线记录电话、邮件、工单和人工备注。自定义字段未知时按键值表降级渲染，不能丢失原数据。

### `/clientsviewservices`

这是客户服务的聚焦详情页：顶部产品名、主机名/IP、状态、到期日和主要操作；中部按凭据、网络、计费、模块和操作日志分卡。密码、Token 和 VNC 信息默认遮罩，查看或复制需要二次验证（若系统支持）。

### `/viewinvoices`

顶部显示账单编号、客户、状态、应付金额和支付时间；主区为账单项目、折扣、税费和合计；右侧为支付、标记已付、退款、下载和发送。已支付账单的金额字段只读，退款显示可退余额和原支付渠道。

### `/ordersadd`

管理员代客户下单采用四段式表单：选择客户 → 选择产品/周期 → 填写配置项 → 预览金额和提交。库存、优惠、税费和权限均由服务端重新计算；提交前显示是否立即开通、是否生成账单以及销售归属。

### `/createsupporttickets`

表单顶部显示客户和关联服务，正文区为部门、主题、优先级、内容、附件和内部可见性；底部显示发送/保存草稿。客户、服务和部门改变时重新校验可用选项，提交后跳转工单详情并显示 ID。

### `/clientsviewemail`

邮件详情采用邮件头摘要（主题、收件人、发送时间、状态）+ 正文 + 附件 + 投递事件时间线。HTML 邮件必须隔离渲染，禁止脚本执行；重发只允许在失败状态并显示收件人和模板变量预览。

## 4. 业务、订单和产品服务页面

### `/orders`

筛选支持订单 ID、客户、产品、付款状态、服务状态、销售和时间；表格列为 ID、客户名、产品、IP、下单时间、金额、付款状态/付款方式、状态、提成/销售。批量标记、取消和导出按权限显示；订单行展开显示账单和服务链路。

### `/orderdetail`

顶部为订单状态、客户、金额、下单时间和主要操作；下方标签为订单条目、账单、服务、配置、事件日志。条目表格列为 ID、条目、描述、付款周期、金额、状态、付款状态、操作。取消、重试开通和改价均显示影响的账单/服务对象。

### `/trafficorder`

表格列为 ID、客户名、产品、时间、金额、付款状态、支付方式、操作。顶部显示流量包订单汇总和库存告警；操作为查看、补发、取消和进入客户服务，库存不足时在提交前阻断。

### `/productlist`

表格列为 ID、客户、产品名称（主机名）、IP、类型、购买时间、到期时间、周期、价格、状态、销售。工具栏支持产品类型、状态、到期区间和销售；操作包括查看服务、续费、暂停、迁移和导出。

### `/cancelrequests`

表格列为用户（公司）、请求时间、产品（主机名）、IP、类型（立即/到期）、原因、删除时间、状态、操作。详情抽屉展示原订单、账单、服务状态和退款影响；批准、拒绝、改为到期取消均需填写原因并显示执行任务。

## 5. 财务页面

### `/transactions`

筛选支持客户、时间、支付方式、类型、销售和流水号；表格列为客户名、时间、付款方式、描述、金额、销售、流水号、类型、操作。详情显示网关回调、关联账单和手续费；退款、冲正和导出按权限控制。

### `/invoices`

表格列为账单、客户名、账单生成日、预期日、总计、付款方式、销售、状态、账单类型、操作。顶部汇总待收、逾期和本期金额；批量发送、标记支付、作废和退款必须显示选中数量和金额合计。

### `/withdrawdeposits`

表格列为 ID、姓名（公司名）、金额、类型、操作人、状态、拒绝原因、时间、操作。审核抽屉展示申请人收款信息、余额冻结状态和历史提现；通过/拒绝/补充资料均要求备注，拒绝原因回显到列表。

### `/receipt`

表格列为发票 ID、用户名、发票抬头、开具类型、发票金额、邮寄地址、申请时间、审核时间、状态、操作。详情显示抬头、税号、地址、关联账单和附件；审核通过、驳回、开具和重开按状态流转，重复点击必须幂等。

### `/configgateways`

列表列为 ID、插件名称、标识、描述、作者、版本、状态、操作。配置页按启用状态、商户参数、回调地址、币种和日志分组；密钥默认遮罩，保存后提示是否需要清缓存或重启队列。网关连接测试不得真实扣款。

### `/configpromotions`

列表列为 ID、优惠码、类型、价值、循环优惠、已使用次数/最大使用次数、开始时间、失效时间、操作。筛选区支持生效、过期和余量；停用、删除和批量导入要显示已生成账单是否受影响。

### `/configpromotionsadd`

表单分优惠码基本信息、固定额/百分比、适用产品与客户组、一次性/循环规则、使用次数、时间窗和叠加规则。右侧实时示例计算，提交前显示冲突规则；编辑已使用优惠码时历史订单只读。

### `/configcurrencies`

表格列为 ID、货币代码、前缀、后缀、格式、汇率、操作。编辑页按显示格式、汇率来源、默认货币和四舍五入分组；切换默认货币前显示现有价格和账单影响。

### `/configfund`

余额/充值配置采用左侧设置分组、右侧表单：最低/最高充值、可用支付方式、手续费、赠送规则、人工调整权限和通知。保存后显示生效范围；人工调整入口必须链接到账务审计。

### `/configreceipt`

表格列为 ID、快递名称、快递价格、操作；编辑表单分快递名称、价格、适用地区和启用状态。发票配置与物流价格变更显示是否影响未处理申请。

## 6. 工单与通知配置

### `/supportticket`

筛选支持关键词、状态、部门、处理人、优先级、未读和时间；表格列为 ID、主题、提交人、状态、处理人、部门、提交时间、上次回复。批量分派、转部门、关闭和导出在工具栏；行展开显示最后一条消息和 SLA。

### `/supportstatistics`

顶部按时间、部门和处理人筛选；指标卡显示处理量、平均响应、平均解决时间和满意度；表格列为处理人、处理工单数、总分、1 分、2 分、3 分、4 分、5 分。空数据保留指标说明，不生成虚构平均值。

### `/configticketdepartments`

列表列为部门名称、描述、是否隐藏、自动回复、操作。编辑页分名称/描述、可见客户组、管理员成员、默认处理人、邮箱转发、自动回复和工作时间；隐藏部门需显示已有工单如何处理。

### `/configticketdepartmentsadd`

新建/编辑采用分步或长表单：基本信息 → 成员和权限 → 自动回复 → 转发和通知 → 预览。保存失败要保留正文和变量；测试转发只发送到明确的测试地址。

### `/configticketstatuses`

表格列为 ID、标题、排序、操作。编辑区分名称、颜色/图标、是否终态、客户可见性和自动动作；改变终态前显示受影响工单数量和迁移方案。

### `/configticketpass`

列表列为部门、产品、屏蔽关键字、自动回复、操作。编辑页使用部门/产品选择、关键字规则、匹配方式、回复模板和启停；规则命中日志可从行操作进入，避免静默拦截。

### `/addhelp`

帮助编辑页按标题、分类、隐藏状态、日期、标签、描述、正文七组字段排列；正文编辑器下方显示预览、字数和链接安全提示。控制器当前提供 `formList`，字段渲染必须按类型处理；保存后显示发布状态和前台链接。

### `/smstemplateindex`

表格列为编号、模板 ID、类型、模板标题、模板内容、审核状态、操作；筛选支持模板 ID 和标题。编辑抽屉显示变量说明、供应商审核状态和示例渲染；删除或重新提交前提示正在使用该模板的场景。

### `/permissionsmanagment`

表格列为 ID、分组名称、说明、状态、组成员、操作。角色详情采用左侧角色摘要、中央权限树、右侧成员和生效范围；保存显示新增/撤销权限差异。高风险权限（财务、授权、系统配置）要求二次确认并记录操作者。

## 7. 商品、配置项和模块页面

### `/configproducts`

表格列为商品名称、类型、定价、库存、已开通/总数量、自动开通、操作。顶部按产品类型、上架状态、模块和库存筛选；行操作进入产品详情、配置项、模块、上下架和复制。库存或自动开通开关变更显示待处理订单影响。

### `/configproduct`

产品详情采用标签页：基本信息、描述/SEO、价格和账期、库存、配置项、服务器模块、上游关联、销售和日志。基本信息与价格表单分组，危险的删除/下架固定在页面底部；保存后分别提示立即生效或下次订购生效。

### `/configproductoptions`

表格列为 ID、组名、描述、产品、操作。顶部支持产品和启用状态筛选；行操作进入配置组、选项和关联产品，删除前显示引用数量。

### `/configproductoptionsgroup`

表单分组名称、描述、显示排序、适用产品、必填和显示条件；右侧显示配置项预览。排序变更使用拖拽后提交差异，移动端提供上下移动按钮。

### `/configproductoptionsedit`

编辑配置项采用“基本信息 → 选项值 → 价格/周期 → 条件与库存 → 前台预览”。每个选项值显示名称、值、加价、库存、默认和启用；修改已被订单使用的值需标记历史兼容。

### `/configproductoptionsaddon`

附加项页使用关联产品摘要 + 附加项表格；字段为附加项名称、类型、价格、周期、数量限制、默认和启用。保存前显示与主产品价格叠加示例。

### `/configtraffic`

流量包配置按名称、流量 GB、价格、启用、已售/库存、创建时间展示列表（控制器当前列定义）。编辑区增加适用产品、结算周期、超额规则和通知阈值；库存不足时禁止继续销售。

### `/configservermodule`

列表显示模块名称、标识、版本、支持能力、状态和操作；配置页分连接参数、能力映射、默认超时、重试、日志级别和授权状态。测试连接只验证握手和只读能力，结果写入模块日志。

### `/configservermoduleedit`

模块编辑页使用步骤条：基本信息 → 凭据/地址 → 能力映射 → 产品关联 → 测试与发布。密钥只显示脱敏值；更换模块版本前显示现有服务数量和回滚方式。

### `/configdcimmoodule`

列表列为 ID、刷新、名称、IP、服务器数量、区域、操作。顶部显示授权/连接状态和最近刷新；行操作为刷新、编辑、查看服务器和禁用。刷新中显示任务进度，失败提供错误摘要和重试。

### `/configdcimmooduleedit`

编辑页分名称/区域、API 地址、凭据、同步策略、产品映射和健康检查。保存后显示是否需要重新同步；删除或解绑前列出受影响资源。

### `/configzjmfcloud`

采用连接向导：云平台名称 → 地址与凭据 → 区域/资源映射 → 健康检查 → 保存。页面顶部持续显示连接状态、最后同步和错误；凭据变更要求再次确认，禁止在日志中回显。

## 8. 资源和上游页面

### `/munualresource`

资源表格列为重装/破解、电源、IP、配置、用户名/密码、上游、成本、关联客户（产品）、到期时间、操作。工具栏支持上游、分配状态、到期区间和电源状态；控制操作与编辑分区，密码默认遮罩。重装、破解、关机等操作显示异步任务和回滚/失败信息。

### `/addOrEditresource`

表单分资源类型与 IP、硬件/配置、登录凭据、上游与成本、关联客户/产品、到期与备注。新建和编辑标题必须明确；覆盖已有凭据前显示受影响服务。保存成功后返回资源列表并定位新行。

### `/upStreamedit`

上游编辑页采用摘要 + 标签：基本信息、API 地址和凭据、产品映射、同步计划、费用/成本、最近同步和错误日志。连接测试、同步和禁用按钮分离；Token 只允许显式查看一次并记审计。

### `/zjmfapi`

View* 返回占位数据，但 `ZjmfFinanceApiController` 已有连接列表、详情、刷新、日志等业务实现，路由见静态盘点中的 `zjmf_finance_api/*`。新模板主区展示接口返回的连接、状态与日志；成功率、重试、最后请求时间只有在对应响应字段和动作确认后才能增加。

## 9. 统计页面

四个 View* 是占位，但 `ReportsController` 已实现下列 GET API。真实参数、字段和统计口径见[接口契约](13-page-api-contract.md)；以下布局不增加接口没有的维度。

### `/annualstatistics`

顶部显示默认币种和分页；汇总卡展示收入 `income`、支出 `expenses`、净额 `last`。中部采用 `year_reports_chart` 的 `chart.years/list` 展示各年净额月度趋势；底部采用 `year_reports` 的 `year_count` 表格。当前接口不接受销售/产品筛选，也没有毛利指标；`all` 为全部交易汇总，不能标成“本年度”。

### `/newcustomer`

顶部只放 `year/month` 选择；主体展示 `new_client` 返回的逐日新增客户、订单、完成订单、工单、已回复工单、取消申请数量。下方表格对应 `client_data`，年份选项用 `new_client_years_group`。当前没有来源分布、销售/客户组筛选或客户明细。

### `/productrevenue`

顶部放 `year/month`，主体按产品组展示组内产品的新订购收入/数量、续费收入/数量和总额；组分页使用 `page/limit`。`product_income` 顶层 `data` 就是产品组数组，每组含 `id/name/products`，分页总数取顶层 `groups_count`，年份选项取顶层 `years`。退款已在计算中扣除；旧注释的 `search_type` 不应渲染为当前可用筛选。

### `/revenueranking`

主区展示 `forward_client` 返回的前 10 名正常客户：姓名、公司、收入、支出、净额、币种前后缀，按净额 `last` 降序。行内可进入客户详情。该 API 无时间、销售、产品组维度参数；跨币种统计口径和空数据表现需运行验证，不能擅自转换币种。

## 10. 页面交付与验收记录

每个入口交付时至少提供：桌面线框、移动线框、字段/表格列截图或接口样例、角色矩阵、空态/错误态、危险操作确认稿和真实路由链接。验收按以下顺序执行：

1. 用默认管理员确认菜单、路由、数据和成功流程；
2. 用无该权限管理员确认菜单隐藏、直接访问拒绝和接口拒绝；
3. 检查筛选、分页、批量操作、刷新、后退、重复提交和过期会话；
4. 检查移动端抽屉、表格卡片、长文本、固定操作栏和键盘遮挡；
5. 对财务、认证、资源控制、插件和权限变更核对审计日志；
6. 对“待确认”页面在接口完成后补齐指标、字段、状态和截图，再把标记改为“已确认”。
